# The 10-Step Storymakers Process

## Overview

The Storymakers Method unfolds across 10 steps, organized into four phases:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  PHASE 0: FOUNDATION                                                        │
│  ┌─────────────────────────────────────────────────────────────────────────┐│
│  │ STEP 0: LAUNCHPAD                                                       ││
│  │ Define: SCQA → Big Idea → 3 Pillars → Block Mapping                     ││
│  └─────────────────────────────────────────────────────────────────────────┘│
├─────────────────────────────────────────────────────────────────────────────┤
│  PHASE 1: BLOCK LEVEL (Strategic Architecture)                              │
│  ┌───────────────────┬───────────────────┬───────────────────┐              │
│  │ STEP 1            │ STEP 2            │ STEP 3            │              │
│  │ Structure the     │ Define the        │ Plan the          │              │
│  │ Problem           │ Journey           │ Evidence          │              │
│  │ (Architect)       │ (Storyteller)     │ (Designer)        │              │
│  └───────────────────┴───────────────────┴───────────────────┘              │
├─────────────────────────────────────────────────────────────────────────────┤
│  PHASE 2: LOOP LEVEL (Argumentative Flow)                                   │
│  ┌───────────────────┬───────────────────┬───────────────────┐              │
│  │ STEP 4            │ STEP 5            │ STEP 6            │              │
│  │ Sequence the      │ Manage the        │ Storyboard the    │              │
│  │ Argument          │ Tension           │ Data              │              │
│  │ (Architect)       │ (Storyteller)     │ (Designer)        │              │
│  └───────────────────┴───────────────────┴───────────────────┘              │
├─────────────────────────────────────────────────────────────────────────────┤
│  PHASE 3: SLIDE LEVEL (Execution & Polish)                                  │
│  ┌───────────────────┬───────────────────┬───────────────────┐              │
│  │ STEP 7            │ STEP 8            │ STEP 9            │              │
│  │ Sharpen the       │ Visualize the     │ Refine the        │              │
│  │ Insight           │ Concept           │ Signal            │              │
│  │ (Architect)       │ (Storyteller)     │ (Designer)        │              │
│  └───────────────────┴───────────────────┴───────────────────┘              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## PHASE 0: FOUNDATION

### Step 0: Launchpad

**Purpose:** Establish the strategic foundation before creating any slides.

**Time Investment:** 20-30% of total project time

**Deliverables:**
1. Completed SCQA framework
2. Big Idea statement
3. 3 Strategic Pillars
4. Block outline (1-3 blocks per pillar)
5. Audience profile
6. Success criteria

**Process:**

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              LAUNCHPAD                                       │
│                                                                              │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐  │
│  │  SITUATION  │───►│COMPLICATION │───►│  QUESTION   │───►│   ANSWER    │  │
│  │             │    │             │    │             │    │ (Big Idea)  │  │
│  └─────────────┘    └─────────────┘    └─────────────┘    └──────┬──────┘  │
│                                                                   │         │
│                            ┌──────────────────────────────────────┘         │
│                            ▼                                                 │
│                  ┌─────────────────────────┐                                │
│                  │    3 STRATEGIC PILLARS   │                                │
│                  └─────────────────────────┘                                │
│                            │                                                 │
│         ┌──────────────────┼──────────────────┐                             │
│         ▼                  ▼                  ▼                             │
│    ┌─────────┐       ┌─────────┐       ┌─────────┐                         │
│    │PILLAR 1 │       │PILLAR 2 │       │PILLAR 3 │                         │
│    └────┬────┘       └────┬────┘       └────┬────┘                         │
│         │                 │                 │                               │
│    ┌────┴────┐       ┌────┴────┐       ┌────┴────┐                         │
│    │ BLOCKS  │       │ BLOCKS  │       │ BLOCKS  │                         │
│    │ (1-3)   │       │ (1-3)   │       │ (1-3)   │                         │
│    └─────────┘       └─────────┘       └─────────┘                         │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

**Key Questions:**
- What does the audience already believe? (Situation)
- What has changed or is at risk? (Complication)
- What must be resolved? (Question)
- What is our answer in one sentence? (Big Idea)
- What 3 things must they believe for our answer to be accepted? (Pillars)

## PHASE 1: BLOCK LEVEL

### Step 1: Structure the Problem (Architect)

**Purpose:** Ensure the logical architecture is sound.

**Tools:** SCQA, MECE, Pyramid Principle

**Activities:**
1. Validate SCQA for each block
2. Check that blocks are MECE (no overlaps, no gaps)
3. Ensure each block advances the argument
4. Map the logical flow between blocks

**Output:**
```
Block Structure Map:
├── Block 1: [Title] — supports Pillar 1
│   └── Key claim: [What this block proves]
├── Block 2: [Title] — supports Pillar 1/2
│   └── Key claim: [What this block proves]
├── Block 3: [Title] — supports Pillar 2
│   └── Key claim: [What this block proves]
└── Block 4: [Title] — supports Pillar 3
    └── Key claim: [What this block proves]
```

**Validation Questions:**
- [ ] Does each block have ONE clear purpose?
- [ ] Are the blocks MECE relative to the Big Idea?
- [ ] Is the sequence logical?
- [ ] Can I remove any block without losing the argument?

---

### Step 2: Define the Journey (Storyteller)

**Purpose:** Map the emotional arc and narrative structure.

**Tools:** Hero's Journey, Big Idea, Sparkline planning

**Activities:**
1. Identify the "hero" (audience segment)
2. Map the emotional journey across blocks
3. Identify key "story moments" (peaks and valleys)
4. Plan the opening hook and closing call-to-action

**Output:**
```
Narrative Arc:
                                                      CALL TO
           INSIGHT                                    ACTION
              ▲                                         ▲
              │        ╱╲                              │
    TENSION   │      ╱    ╲           ╱╲              │
              │    ╱        ╲       ╱    ╲           │
              │  ╱            ╲   ╱        ╲         │
              │╱                ╲╱            ╲───────┘
    ──────────┼─────────────────────────────────────────►
           HOOK    Block 1    Block 2    Block 3    Close
```

**Validation Questions:**
- [ ] Is there a clear beginning, middle, end?
- [ ] Does tension rise and fall appropriately?
- [ ] Are there emotional peaks at key moments?
- [ ] Will the audience care?

---

### Step 3: Plan the Evidence (Designer)

**Purpose:** Inventory the visual assets and data needed.

**Tools:** Plausibility Loop, Evidence Matrix

**Activities:**
1. List every claim that needs proof
2. Identify data sources for each claim
3. Determine best visual type for each data point
4. Flag gaps where evidence is missing

**Output:**
```
Evidence Inventory:
┌─────────┬────────────────────┬──────────────┬─────────────┬────────┐
│ Block   │ Claim              │ Evidence     │ Visual Type │ Status │
├─────────┼────────────────────┼──────────────┼─────────────┼────────┤
│ Block 1 │ Market is growing  │ Industry rpt │ Line chart  │ ✓ Have │
│ Block 1 │ We're losing share │ Internal     │ Bar chart   │ ✓ Have │
│ Block 2 │ Customers unhappy  │ NPS data     │ Score card  │ ⚠ Need │
│ Block 3 │ Solution works     │ Case study   │ Before/After│ ⚠ Need │
└─────────┴────────────────────┴──────────────┴─────────────┴────────┘
```

**Validation Questions:**
- [ ] Is every key claim supported by evidence?
- [ ] Do I have the data I need?
- [ ] Is there visual variety across the presentation?
- [ ] Are sources credible?

## PHASE 2: LOOP LEVEL

### Step 4: Sequence the Argument (Architect)

**Purpose:** Structure the logical flow within each block.

**Tools:** Deductive/Inductive logic, Pyramid sub-structures

**Activities:**
1. Break each block into 2-4 loops
2. Choose deductive or inductive structure for each
3. Ensure each loop has a clear conclusion
4. Plan transitions between loops

**Output:**
```
Block 1: "The Market Opportunity"
├── Loop 1.1: Market size is large and growing (Inductive)
│   ├── Slide: Global market data
│   ├── Slide: Growth drivers
│   └── Slide: Synthesis → "The market will double by 2027"
├── Loop 1.2: We're well-positioned to capture share (Deductive)
│   ├── Slide: Our capabilities match market needs
│   ├── Slide: Competitors are vulnerable
│   └── Slide: Conclusion → "We can win"
└── BLOCK CONCLUSION: "This is a once-in-a-decade opportunity"
```

**Validation Questions:**
- [ ] Does each loop build to a clear point?
- [ ] Is the logic type (deductive/inductive) appropriate?
- [ ] Are transitions smooth?
- [ ] Does the block conclusion follow from the loops?

---

### Step 5: Manage the Tension (Storyteller)

**Purpose:** Create engagement through contrast and pacing.

**Tools:** Sparklines, Contrast pairs, Pacing

**Activities:**
1. Map tension levels across each loop
2. Add contrast (problem/solution, before/after)
3. Place "story moments" at strategic points
4. Adjust pacing (faster in middle, slower at key insights)

**Output:**
```
Loop Tension Map:

Loop 1.1:  ───╱╲───╱╲───▲  (Build to insight)
                        │
Loop 1.2:  ▼───────╱╲───┘  (Release then build again)

Loop 1.3:  ───────────▲    (Build to climax)
```

**Validation Questions:**
- [ ] Does each loop have its own mini-arc?
- [ ] Is there contrast that creates engagement?
- [ ] Are there moments of relief after tension?
- [ ] Does pacing match content importance?

---

### Step 6: Storyboard the Data (Designer)

**Purpose:** Plan how data will be revealed and visualized.

**Tools:** Reveal vs. Headline, Data story arc, Chart selection

**Activities:**
1. Decide reveal strategy for each data point
2. Sequence visualizations within loops
3. Plan progressive builds where appropriate
4. Design data "moments" for key insights

**Output:**
```
Data Storyboard for Loop 1.2:
┌─────────┬────────────────────┬─────────────────────────────────┐
│ Slide   │ Data Point         │ Reveal Strategy                 │
├─────────┼────────────────────┼─────────────────────────────────┤
│ Slide 1 │ Market share trend │ Headline: "We've lost 8 points" │
│         │                    │ Then show the chart             │
├─────────┼────────────────────┼─────────────────────────────────┤
│ Slide 2 │ Competitor moves   │ Progressive: Show each          │
│         │                    │ competitor one by one           │
├─────────┼────────────────────┼─────────────────────────────────┤
│ Slide 3 │ Customer feedback  │ Quote first, then data          │
│         │                    │ to support emotionally          │
└─────────┴────────────────────┴─────────────────────────────────┘
```

**Validation Questions:**
- [ ] Is each data reveal intentional?
- [ ] Do visualizations build on each other?
- [ ] Is there variety in chart types?
- [ ] Will the data be memorable?

## PHASE 3: SLIDE LEVEL

### Step 7: Sharpen the Insight (Architect)

**Purpose:** Ensure every slide title communicates the key insight.

**Tools:** Action Titles, "So What?" test, Headline test

**Activities:**
1. Write action titles for every slide
2. Verify each title passes "So What?" test
3. Remove or merge slides without clear insights
4. Ensure body content supports (not repeats) the title

**Output:**
```
Slide Title Audit:
┌────────────────────────────────────┬─────────────────────────────────────────┐
│ Original (Descriptive)             │ Revised (Action Title)                  │
├────────────────────────────────────┼─────────────────────────────────────────┤
│ "Market Overview"                  │ "The market will double in 5 years,     │
│                                    │  creating $50B in new opportunity"      │
├────────────────────────────────────┼─────────────────────────────────────────┤
│ "Competitive Analysis"             │ "Three competitors are vulnerable to    │
│                                    │  disruption—we can take their share"    │
├────────────────────────────────────┼─────────────────────────────────────────┤
│ "Customer Feedback"                │ "Customers are begging for a solution   │
│                                    │  we're uniquely positioned to provide"  │
└────────────────────────────────────┴─────────────────────────────────────────┘
```

**Validation Questions:**
- [ ] Could someone understand the argument from titles alone?
- [ ] Does every title state an insight, not just a topic?
- [ ] Is there ONE clear takeaway per slide?
- [ ] Does the body support the title?

---

### Step 8: Visualize the Concept (Storyteller)

**Purpose:** Bring abstract ideas to life visually.

**Tools:** Metaphor, Layouts, Story moments

**Activities:**
1. Identify slides that need conceptual visualization
2. Choose or create metaphors for abstract concepts
3. Select layouts that support the message
4. Design key "story moment" slides

**Output:**
```
Concept Visualization Plan:
┌────────────────────────────┬──────────────────────────────────────────────┐
│ Concept                    │ Visualization Approach                       │
├────────────────────────────┼──────────────────────────────────────────────┤
│ Market disruption          │ Metaphor: "Tidal wave" imagery               │
│                            │ Layout: Full-bleed dramatic image            │
├────────────────────────────┼──────────────────────────────────────────────┤
│ Our solution framework     │ Metaphor: "Three pillars holding up roof"    │
│                            │ Layout: Architectural diagram                │
├────────────────────────────┼──────────────────────────────────────────────┤
│ Transformation journey     │ Metaphor: "From caterpillar to butterfly"    │
│                            │ Layout: Before/After split screen            │
└────────────────────────────┴──────────────────────────────────────────────┘
```

**Validation Questions:**
- [ ] Are metaphors clear and consistent?
- [ ] Do layouts support the content?
- [ ] Will abstract concepts be understood?
- [ ] Are story moment slides impactful?

---

### Step 9: Refine the Signal (Designer)

**Purpose:** Maximize clarity and minimize noise on every slide.

**Tools:** Data-Ink Ratio, Squint test, 3-second rule

**Activities:**
1. Audit every slide for visual noise
2. Remove unnecessary elements
3. Emphasize key data points
4. Ensure visual consistency

**Output:**
```
Visual Refinement Checklist:
For each slide:
├── [ ] Remove unnecessary gridlines
├── [ ] Eliminate redundant labels
├── [ ] Highlight key data point
├── [ ] Check color contrast/accessibility
├── [ ] Verify font sizes (readable from back)
├── [ ] Remove decorative elements
├── [ ] Ensure consistent style
└── [ ] Add source attribution
```

**Validation Questions:**
- [ ] Does every slide pass the squint test?
- [ ] Can the main point be grasped in 3 seconds?
- [ ] Is there ONE clear focal point?
- [ ] Have I removed everything I can?

---

## Process Summary

| Phase | Steps | Primary Focus | Key Question |
|-------|-------|---------------|--------------|
| 0: Foundation | 0 | Strategic clarity | "What's the core message?" |
| 1: Blocks | 1-3 | Architecture | "Is the structure sound?" |
| 2: Loops | 4-6 | Flow | "Does it engage?" |
| 3: Slides | 7-9 | Execution | "Is it clear?" |

---

## Time Allocation Guide

For a typical presentation project:

| Phase | % of Time | Activities |
|-------|-----------|------------|
| Launchpad | 20-30% | Research, SCQA, planning |
| Block Level | 20-25% | Structure, narrative arc, evidence plan |
| Loop Level | 25-30% | Sequencing, storyboarding, data planning |
| Slide Level | 20-25% | Writing, visualization, polish |

> **Critical insight:** Most people spend 80% of time on slides and 20% on planning. Inverting this ratio produces dramatically better results.
